Файл содержит только ещё не устранённые проблемы и будущие улучшения. Завершённые пункты следует удалять; текущее поведение документируется в `README.md`.

## Отложенные протоколы интеграции

Реализовывать только после появления подтверждённого потребителя и согласованных требований:

- SAML 2.0.
- SCIM.
- OAuth 2.0 Token Exchange (RFC 8693).

До реализации определить модель угроз, сценарии, совместимые продукты и критерии приёмки.
